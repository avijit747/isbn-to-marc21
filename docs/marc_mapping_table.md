# MARC21 Field Mapping Table (ISBN.gov.in Metadata → MARC21)

This file summarizes the **field-level mapping** used by the *ISBN to MARC21 Converter* to transform ISBN registration metadata from **isbn.gov.in** into **MARC21** bibliographic records. The mapping aligns with **RDA** practices and MARC21 conventions, and is intended to support transparency, reproducibility, and peer review.

---

## A. Input Metadata Fields (Expected Columns)

Typical columns downloaded from isbn.gov.in (Excel/CSV):

- **Book Title**
- **ISBN**
- **Product Form**
- **Language**
- **Applicant Type**
- **Name of Publishing Agency/Publisher**
- **Name of Author/Editor**
- **Publication Date**

> **Note:** The script renames these columns internally for processing (e.g., `Book Title` → `Book_Title`).

---

## B. Primary Mapping Table

| Source Metadata Field | MARC21 Field | Subfields / Indicators | Rule / Notes |
|---|---:|---|---|
| (System-generated) | **LDR** | `00000nam a2200000 a 4500` | Leader template used for all records |
| Publication Date | **008** | fixed-length | YYMMDD entered-on-file generated by system; year extracted from date; place set to `ii `; language set to ISO 639-2 |
| (Org/Institution code) | **040** | `$a $b $e $c` | `$a` and `$c` use user-entered org code; `$b eng`; `$e RDA` |
| (Constant note) | **588** | `$a` | `Description based on ISBN registration metadata from isbn.gov.in.` |
| ISBN | **020** | `$a` | Non-numeric chars removed; stored in `$a` |
| Name of Author/Editor | **100 / 110** | `$a $e` | First contributor becomes main entry: **100** (personal) or **110** (corporate); relator set to `author` or `editor` |
| Name of Author/Editor | **700 / 710** | `$a $e` | Additional contributors: **700** (personal) / **710** (corporate) with relator `author` or `editor` |
| Book Title | **245** | ind1/ind2, `$a $b $c $n $h` | ind1=`1` if 1XX present else `0`; ind2 computed from initial article; `$a` title; `$b` subtitle (split on `:` or `=`); `$c` responsibility (cleaned); `$n` extracted part/vol info; `$h` medium if bracketed |
| Book Title (edition embedded) | **250** | `$a` | Edition extracted from title patterns (e.g., “2nd ed.”, “Revised edition”); removed from 245 |
| Publisher | **264** | `\1` + `$a $b $c` | `$a India` (fixed); `$b` normalized publisher name; `$c` year if extracted/valid |
| Book Title (series detected) | **490** | ind1=`0`, `$a $v $x` | Series extracted from title using heuristics; optional `$v` numbering; optional `$x` ISSN when labeled |
| Applicant Type | **590** | `$a` | Stored as local provenance note: `ISBN applicant type: ...` |
| Language | **041** | ind1=`0`, `$a` | Emitted only when raw language suggests multiple languages (contains separators like `; , / & and`) |
| Product Form | **655** | `\7` + `$a $2` | Stored as local form/genre: `$a <product form>`; `$2 local` |
| Product Form → RDA | **336** | `$a $2` | `text` or `spoken word` based on product form; `$2 rdacontent` |
| Product Form → RDA | **337** | `$a $2` | `unmediated` / `computer` / `audio`; `$2 rdamedia` |
| Product Form → RDA | **338** | `$a $2` | `volume` / `online resource`; `$2 rdacarrier` |
| (Removed) | **300** | — | **Not generated**: ISBN metadata lacks reliable extent/pagination; to avoid inaccurate physical description, MARC 300 is omitted |

## C. Output Files Produced

| Output | File Extension | Description |
|---|---|---|
| Binary MARC21 | `.mrc` | For direct import into Koha and other MARC-based ILS |
| MARC text (readable) | `.mrk` | For human validation, debugging, and training |

Users can choose to generate **.mrc**, **.mrk**, or **both**.

---

## D. Important Design Decisions

1. **No MARC 300 field**: extent/pagination is not available or reliable in ISBN registrations.
2. Records are intended as **base-level bibliographic records**, suitable for later enhancement (subjects, classification, authority control).
3. Corporate vs personal contributors are detected using keyword heuristics (e.g., *University, Institute, Ltd, Government*).
